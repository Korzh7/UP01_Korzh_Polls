## Описание проекта

Проект представляет собой десктопное приложение на платформе **WPF (.NET / C#)** и базу данных Microsoft SQL Server для проведения анкетирования, опросов и голосований пользователей.

В директории `db/` расположен скрипт создания структуры базы данных `schema.sql` и первичное наполнение тестовыми данными.
